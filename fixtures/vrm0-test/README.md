# VRM 0.x fixture

Place a legally redistributable VRM 0.x test model here as `model.vrm` when running local integration checks. The fixture should include a humanoid head and, when possible, eye bones plus blink/mouth expressions. Do not commit a model without confirming its redistribution license.

The loader identifies this generation from `VRM.meta.version` and reports unsupported capabilities rather than assuming every expression or eye landmark exists.
